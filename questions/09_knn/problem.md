# KNN

## 背景

K 近邻不训练显式参数，而是直接利用训练样本之间的局部距离完成预测。它既能用于分类，也能用于回归，是理解距离度量、邻域决策和惰性学习的经典算法。 本题要求只使用 NumPy 完成核心计算，以便直接观察张量形状和数值过程。

## 需求

实现 `knn_predict`。使用欧氏距离，为每个查询样本选取距离最小的 k 个训练样本。分类时进行多数投票，票数相同选择数值更小的标签；回归时返回邻居目标值的算术平均。距离相同时必须保持训练样本的原始顺序。 所有输入均保证合法，不需要处理题目约定以外的类型、形状或取值。

## 输入

- `train_x`：形状为 (num_train, num_features) 的 float64 训练特征。
- `train_y`：形状为 (num_train,) 的整数标签或浮点回归目标。
- `query_x`：形状为 (num_queries, num_features) 的 float64 查询特征。
- `k`：邻居数，满足 1 <= k <= num_train。
- `task`：字符串 classification 或 regression。

除特别说明外，参与数值计算的数组和常量统一按 `float64` 处理。函数不应修改调用者传入的数组。

## 输出

返回形状为 `(num_queries,)` 的预测数组。分类结果保持标签 dtype，回归结果为 float64。

## 数学定义

欧氏距离为 $d(x,q)=\sqrt{\sum_j(x_j-q_j)^2}$。分类取邻居众数，回归取 $\hat y=\frac1k\sum_{i\in N_k(q)}y_i$。

## 测试约定

固定随机种子生成 100 组输入输出，覆盖分类、回归、不同特征维数与 k、单查询和多查询、负值、距离并列及投票并列。本题判定误差为 `rtol=1e-10`、`atol=1e-12`。测试只调用公开函数，不依赖标准输出；提交代码中可以定义私有辅助函数。
