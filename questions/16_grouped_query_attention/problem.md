# Grouped-Query Attention

## 背景

分组查询注意力位于 MHA 与 MQA 之间：查询头分成若干组，每组共享一个 K/V 头。它在模型质量、KV 缓存大小和推理吞吐之间提供折中。 本题要求只使用 NumPy 完成核心计算，以便直接观察张量形状和数值过程。

## 需求

实现 `grouped_query_attention`。查询头数必须能被 KV 头数整除。将连续的 num_query_heads/num_kv_heads 个查询头映射到同一个 KV 头，计算缩放点积注意力，拼接后通过输出投影。 所有输入均保证合法，不需要处理题目约定以外的类型、形状或取值。

## 输入

- `x`：形状为 (L,D) 的 float64 输入。
- `w_q`：形状为 (D,D) 的查询投影。
- `w_k / w_v`：形状为 (D, num_kv_heads*head_dim)。
- `w_o`：形状为 (D,D)。
- `num_query_heads / num_kv_heads`：查询头数和 KV 头数。
- `mask`：None 或 (L,L) 布尔掩码。

除特别说明外，参与数值计算的数组和常量统一按 `float64` 处理。函数不应修改调用者传入的数组。

## 输出

返回形状为 `(L,D)` 的注意力输出。

## 数学定义

令 $g=H_q/H_{kv}$，查询头 h 使用 KV 头 $\lfloor h/g\rfloor$。注意力缩放因子仍为 $\sqrt{d_h}$。

## 测试约定

固定随机种子生成 100 组输入输出，覆盖MHA 退化情形、MQA 退化情形、多个分组、不同掩码和序列长度。本题判定误差为 `rtol=1e-8`、`atol=1e-10`。测试只调用公开函数，不依赖标准输出；提交代码中可以定义私有辅助函数。
