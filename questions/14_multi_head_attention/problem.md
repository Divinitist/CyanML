# Multi-Head Attention

## 背景

多头注意力让模型在多个独立子空间中建立序列位置之间的联系，再合并各头信息。它是 Transformer 的核心算子，本题实现不含偏置和 dropout 的单批次版本。 本题要求只使用 NumPy 完成核心计算，以便直接观察张量形状和数值过程。

## 需求

实现 `multi_head_attention`。分别计算 Q、K、V 投影，将模型维度均分为 num_heads 个头，执行缩放点积注意力后拼接所有头并乘输出矩阵。可选布尔 mask 中 True 表示允许关注；每个查询位置保证至少有一个可见键。 所有输入均保证合法，不需要处理题目约定以外的类型、形状或取值。

## 输入

- `x`：形状为 (sequence_length, model_dim) 的 float64 序列。
- `w_q / w_k / w_v / w_o`：四个形状均为 (model_dim, model_dim) 的投影矩阵。
- `num_heads`：注意力头数，能整除 model_dim。
- `mask`：None 或形状为 (L,L) 的布尔数组。

除特别说明外，参与数值计算的数组和常量统一按 `float64` 处理。函数不应修改调用者传入的数组。

## 输出

返回形状为 `(L, model_dim)` 的注意力输出。

## 数学定义

$A=\operatorname{softmax}(QK^T/\sqrt{d_h})$，每个头的上下文为 $AV$。

## 测试约定

固定随机种子生成 100 组输入输出，覆盖不同序列长度、头数、头维度、无掩码与因果掩码。本题判定误差为 `rtol=1e-9`、`atol=1e-11`。测试只调用公开函数，不依赖标准输出；提交代码中可以定义私有辅助函数。
