# 决策树最佳划分

## 背景

分类决策树通过选择特征和阈值，使子节点比父节点更纯。本题只实现一个节点的穷举划分，是 CART 和信息增益树的核心步骤。 本题要求只使用 NumPy 完成核心计算，以便直接观察张量形状和数值过程。

## 需求

实现 `best_decision_tree_split`。对每个特征排序后的相邻不同取值取中点作为候选阈值，计算父节点纯度减去左右子节点加权纯度的增益。criterion 支持 gini 和 entropy。增益并列时保留特征下标更小、阈值更小的候选。 所有输入均保证合法，不需要处理题目约定以外的类型、形状或取值。

## 输入

- `x`：形状为 (num_samples, num_features) 的 float64 特征矩阵。
- `labels`：形状为 (num_samples,) 的整数分类标签。
- `criterion`：字符串 gini 或 entropy。

除特别说明外，参与数值计算的数组和常量统一按 `float64` 处理。函数不应修改调用者传入的数组。

## 输出

返回 `(feature_index, threshold, gain)`，分别是最佳特征下标、浮点阈值和纯度增益。输入保证至少存在一个有效候选阈值。

## 数学定义

Gini 为 $1-\sum_cp_c^2$，Entropy 为 $-\sum_cp_c\log_2p_c$；增益为 $I(P)-\frac{N_L}{N}I(L)-\frac{N_R}{N}I(R)$。

## 测试约定

固定随机种子生成 100 组输入输出，覆盖两种纯度、多分类、重复特征值、完美划分、弱增益、多特征及并列决策。本题判定误差为 `rtol=1e-9`、`atol=1e-11`。测试只调用公开函数，不依赖标准输出；提交代码中可以定义私有辅助函数。
