# 二分类 F1-score

## 背景

F1-score 是精确率与召回率的调和平均，在正负类别不均衡时比单纯准确率更关注正类识别质量。

## 需求

实现 `binary_f1_score`。输入是已经离散化的二分类预测与真实标签。若分母 `2TP + FP + FN` 为零，返回 `0.0`。不得修改输入数组。

## 输入

- `predictions`：形状为 `(num_samples,)` 的整数数组，元素只为 `0` 或 `1`。
- `targets`：同形整数数组，元素只为 `0` 或 `1`。

## 输出

返回 Python 浮点数，表示正类标签 `1` 的 F1-score。

## 数学定义

$$
F_1=\frac{2TP}{2TP+FP+FN}.
$$

## 测试约定

共运行 100 组输入，覆盖全对、全错、全零预测、全一预测、无正类目标、类别不均衡和随机标签。结果以 scikit-learn 为独立基准，误差标准为 `rtol=0`、`atol=0`。
