# 二分类 AUC

## 背景

ROC-AUC 衡量二分类模型把随机正样本排在随机负样本之前的概率。它只依赖预测分数的相对顺序，不要求分数已经归一化为概率。

## 需求

实现 `binary_auc`。输入保证同时包含正类和负类。分数相同时按平均秩处理：正负样本同分的一对贡献 `0.5`。不得修改输入数组。

## 输入

- `scores`：形状为 `(num_samples,)` 的 `float64` 数组，表示正类预测分数。
- `labels`：同形整数数组，元素只为 `0` 或 `1`。

## 输出

返回 Python 浮点数，表示 ROC 曲线下面积，范围为 `[0, 1]`。

## 数学定义

设正样本集合为 $P$，负样本集合为 $N$，则

$$
\mathrm{AUC}=\frac{1}{|P||N|}\sum_{p\in P}\sum_{n\in N}
\left(\mathbb{1}[s_p>s_n]+\frac{1}{2}\mathbb{1}[s_p=s_n]\right).
$$

## 测试约定

共运行 100 组输入，覆盖完全正确和完全反向排序、随机分数、大量并列分数、不同类别比例、整体平移和正比例缩放。结果以 scikit-learn 为独立基准，误差标准为 `rtol=1e-12`、`atol=1e-12`。
