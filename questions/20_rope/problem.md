# RoPE

## 背景

旋转位置编码把绝对位置表示为 Q/K 各二维子空间中的旋转，使点积自然依赖相对位置。它不向残差流直接添加位置向量，是现代解码器模型的常见选择。 本题要求只使用 NumPy 完成核心计算，以便直接观察张量形状和数值过程。

## 需求

实现 `apply_rope`。对 Q/K 的前 rotary_dim 维按相邻偶、奇维配对旋转，其余维保持不变。rotary_dim=None 表示旋转整个头维度。输入旋转维数保证为正偶数，position_ids 可从任意非负位置开始。 所有输入均保证合法，不需要处理题目约定以外的类型、形状或取值。

## 输入

- `q / k`：形状为 (sequence_length, num_heads, head_dim) 的 float64 数组。
- `position_ids`：形状为 (sequence_length,) 的位置数组。
- `base`：RoPE 频率基数。
- `rotary_dim`：None 或不超过 head_dim 的正偶数。

除特别说明外，参与数值计算的数组和常量统一按 `float64` 处理。函数不应修改调用者传入的数组。

## 输出

返回旋转后的 `(q_rotated, k_rotated)`，两者形状不变且不修改输入。

## 数学定义

对每对 $(x_0,x_1)$ 应用 $[x_0\cos\theta-x_1\sin\theta, x_0\sin\theta+x_1\cos\theta]$。

## 测试约定

固定随机种子生成 100 组输入输出，覆盖部分和全部旋转维、不同头数、位置偏移、头维度和保持不变的尾部。本题判定误差为 `rtol=1e-8`、`atol=1e-10`。测试只调用公开函数，不依赖标准输出；提交代码中可以定义私有辅助函数。
