# Sliding-Window Attention

## 背景

滑动窗口注意力把全局二次复杂度限制为局部窗口，适合处理长序列。本题使用因果窗口，因此当前位置不能读取未来 token。 本题要求只使用 NumPy 完成核心计算，以便直接观察张量形状和数值过程。

## 需求

实现 `sliding_window_attention`。完成标准多头 Q/K/V 投影。位置 i 只能关注从 max(0,i-window_size+1) 到 i 的键；在允许区域内计算稳定 softmax，拼接各头并做输出投影。window_size 大于序列长度时等价于完整因果注意力。 所有输入均保证合法，不需要处理题目约定以外的类型、形状或取值。

## 输入

- `x`：形状为 (L,D) 的 float64 序列。
- `w_q / w_k / w_v / w_o`：四个 (D,D) 投影矩阵。
- `num_heads`：能整除 D 的注意力头数。
- `window_size`：正整数窗口宽度，包含当前位置。

除特别说明外，参与数值计算的数组和常量统一按 `float64` 处理。函数不应修改调用者传入的数组。

## 输出

返回形状为 `(L,D)` 的局部因果注意力结果。

## 数学定义

可见条件为 $j\le i$ 且 $j\ge i-w+1$；可见分数再按最后一维执行 softmax。

## 测试约定

固定随机种子生成 100 组输入输出，覆盖窗口为 1、窗口覆盖全序列、不同长度、不同头数和边界位置。本题判定误差为 `rtol=1e-8`、`atol=1e-10`。测试只调用公开函数，不依赖标准输出；提交代码中可以定义私有辅助函数。
