# 相对位置编码

## 背景

相对位置偏置直接修改注意力 logits，让模型根据查询和键之间的距离调整注意力。它可以是固定函数，也可以来自可学习查找表。 本题要求只使用 NumPy 完成核心计算，以便直接观察张量形状和数值过程。

## 需求

实现 `relative_position_bias`。支持 alibi 和 table 两种模式。alibi 为每个头使用斜率 2^(-8(h+1)/H)，偏置为斜率乘负绝对距离；table 模式把有符号距离 key-query 截断到给定范围，再查询每个头自己的表。 所有输入均保证合法，不需要处理题目约定以外的类型、形状或取值。

## 输入

- `query_length / key_length`：查询和键的正整数长度，可以不同。
- `num_heads`：注意力头数。
- `mode`：字符串 alibi 或 table。
- `max_distance`：table 模式的最大有符号距离。
- `table`：table 模式下形状为 (H,2*max_distance+1)；alibi 时为 None。

除特别说明外，参与数值计算的数组和常量统一按 `float64` 处理。函数不应修改调用者传入的数组。

## 输出

返回形状为 `(num_heads, query_length, key_length)` 的 float64 偏置，可直接加到注意力分数。

## 数学定义

相对距离 $r=j-i$；table 索引为 $clip(r,-M,M)+M$，ALiBi 为 $-2^{-8(h+1)/H}|r|$。

## 测试约定

固定随机种子生成 100 组输入输出，覆盖两种模式、不等长序列、不同头数、距离截断、单位置及多种表值。本题判定误差为 `rtol=1e-8`、`atol=1e-10`。测试只调用公开函数，不依赖标准输出；提交代码中可以定义私有辅助函数。
