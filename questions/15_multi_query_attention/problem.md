# Multi-Query Attention

## 背景

多查询注意力保留多个查询头，但让所有查询头共享同一组键和值。与标准多头注意力相比，它显著减少自回归推理时 KV Cache 的体积。 本题要求只使用 NumPy 完成核心计算，以便直接观察张量形状和数值过程。

## 需求

实现 `multi_query_attention`。w_q 投影到完整模型维度，w_k 和 w_v 仅投影到一个头维度。每个查询头分别与共享 K/V 计算缩放点积注意力，随后拼接并做输出投影。布尔掩码语义与多头注意力一致。 所有输入均保证合法，不需要处理题目约定以外的类型、形状或取值。

## 输入

- `x`：形状为 (L,D) 的 float64 输入。
- `w_q`：形状为 (D,D)。
- `w_k / w_v`：形状为 (D, head_dim)。
- `w_o`：形状为 (D,D)。
- `num_query_heads`：查询头数，head_dim=D/H。
- `mask`：None 或形状为 (L,L) 的布尔掩码。

除特别说明外，参与数值计算的数组和常量统一按 `float64` 处理。函数不应修改调用者传入的数组。

## 输出

返回形状为 `(L,D)` 的 float64 数组。

## 数学定义

$A_h=\operatorname{softmax}(Q_hK^T/\sqrt{d_h})$；所有 h 使用相同的 K 和 V。

## 测试约定

固定随机种子生成 100 组输入输出，覆盖不同查询头数、头维度、序列长度、共享 K/V、无掩码和因果掩码。本题判定误差为 `rtol=1e-8`、`atol=1e-10`。测试只调用公开函数，不依赖标准输出；提交代码中可以定义私有辅助函数。
