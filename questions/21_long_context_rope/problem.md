# 长上下文 RoPE

## 背景

直接把 RoPE 外推到远超训练长度的位置可能导致频率分布失配。线性插值和动态 NTK 基数缩放是两种常见的简化扩展策略。 本题要求只使用 NumPy 完成核心计算，以便直接观察张量形状和数值过程。

## 需求

实现 `apply_scaled_rope`。method=linear 时将所有 position_ids 除以 scale 后使用原 base；method=ntk 时位置不变，将基数改为 base*scale^(d/(d-2))。随后对全部偶数头维执行标准 RoPE 旋转，头维保证为大于 2 的偶数。 所有输入均保证合法，不需要处理题目约定以外的类型、形状或取值。

## 输入

- `q / k`：形状为 (L,H,d) 的 float64 数组。
- `position_ids`：形状为 (L,) 的绝对位置。
- `scale`：大于等于 1 的上下文扩展倍率。
- `method`：字符串 linear 或 ntk。
- `base`：原始 RoPE 基数。

除特别说明外，参与数值计算的数组和常量统一按 `float64` 处理。函数不应修改调用者传入的数组。

## 输出

返回缩放旋转后的 Q/K 二元组，形状与输入一致。

## 数学定义

linear 使用 $p'=p/s$；ntk 使用 $base'=base\cdot s^{d/(d-2)}$，频率仍为 $base'^{-2i/d}$。

## 测试约定

固定随机种子生成 100 组输入输出，覆盖两种扩展方法、不同倍率、大位置编号、多个头和多个偶数头维。本题判定误差为 `rtol=1e-8`、`atol=1e-10`。测试只调用公开函数，不依赖标准输出；提交代码中可以定义私有辅助函数。
