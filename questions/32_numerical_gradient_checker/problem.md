# 数值梯度检查器

## 背景

手写反向传播时，中心差分可以用纯前向计算近似每个参数的偏导，从而检查解析梯度。它速度较慢，但非常适合定位小规模实现中的链式法则错误。 本题只使用 NumPy 展开核心计算，重点是理解数据流、张量形状和数值细节。

## 需求

实现 `check_gradient`。对 x 的每个元素分别加减 epsilon，调用返回标量 float 的 function，并用中心差分计算数值梯度。每次扰动后必须恢复原值，且不得修改调用者传入的 x。计算解析梯度与数值梯度的逐元素相对误差，分母为 max(1,|a|,|n|)，返回最大误差及其是否不超过 tolerance。 所有输入均符合下述约束，不要求处理非法参数，也不得修改调用者传入的数组。

## 输入

- `function`：接收一个与 x 同形数组并返回标量的纯函数。
- `x`：任意形状的小型 float64 数组。
- `analytic_gradient`：与 x 同形的解析梯度。
- `epsilon`：中心差分的正扰动步长。
- `tolerance`：最大相对误差阈值。

除特别说明外，参与计算的数组和浮点常量均使用 `float64`。

## 输出

返回 `(numerical_gradient, max_relative_error, passed)`；梯度与 x 同形，误差为 Python float，passed 为 Python bool。

## 数学定义

$g_i^{num}=[f(x+\epsilon e_i)-f(x-\epsilon e_i)]/(2\epsilon)$；相对误差为 $|g_i^{num}-g_i|/max(1,|g_i^{num}|,|g_i|)$。

## 测试约定

使用固定随机种子生成 100 组输入输出，覆盖线性、平方、三次、sin、exp 和矩阵二次型，不同数组形状、步长、正确梯度及刻意偏移的错误梯度。本题误差标准为 `rtol=1e-9`、`atol=1e-11`。测试仅调用公开函数，答案所需的实现提示应写在答案代码注释中，而不是题面中。
