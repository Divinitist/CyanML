# 绝对位置编码

## 背景

不含循环和卷积的注意力本身无法区分 token 顺序。正弦绝对位置编码使用不同频率的 sin/cos 信号，把确定性的位置信息直接加到词向量上。 本题要求只使用 NumPy 完成核心计算，以便直接观察张量形状和数值过程。

## 需求

实现 `add_sinusoidal_position_encoding`。为 x 的每个位置构造位置编码。偶数维使用 sin，奇数维使用 cos；奇数模型维度时最后一个偶数维仍需正确计算。start_position 允许为分块序列指定全局起始位置，函数不得修改原数组。 所有输入均保证合法，不需要处理题目约定以外的类型、形状或取值。

## 输入

- `x`：形状为 (sequence_length, model_dim) 的 float64 数组。
- `start_position`：第一个 token 的非负绝对位置。
- `base`：控制频率跨度的正浮点数。

除特别说明外，参与数值计算的数组和常量统一按 `float64` 处理。函数不应修改调用者传入的数组。

## 输出

返回与 x 同形状的 `x + position_encoding`。

## 数学定义

$PE_{p,2i}=\sin(p/base^{2i/d})$，$PE_{p,2i+1}=\cos(p/base^{2i/d})$。

## 测试约定

固定随机种子生成 100 组输入输出，覆盖奇偶模型维度、不同起始位置、序列长度、base 和输入数值。本题判定误差为 `rtol=1e-10`、`atol=1e-12`。测试只调用公开函数，不依赖标准输出；提交代码中可以定义私有辅助函数。
